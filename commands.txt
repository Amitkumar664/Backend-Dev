Exercise 1: Basic Git Workflow
1.Create a new directory and initialize Git
mkdir GitPractice
cd GitPractice
git init

2.Create a README.md file
touch README.md
echo "# Git Practice Repository" > README.md

3.Add and commit the file
git add README.md
git commit -m "Add README file"

4.Make changes and commit again
echo "This repository is for practicing Git basics." >> README.md
git add README.md
git commit -m "Update README content"

5.View commit history
git log
git log --oneline

Exercise 2: Branching and Merging
1.Create a new branch called feature
git checkout -b feature

2.Add new files in the feature branch
touch feature.txt
echo "This is a feature branch file" > feature.txt
git add feature.txt
git commit -m "Add feature file"

3.Switch back to main branch
git checkout main

4.Merge feature branch into main
git merge feature

5.Delete the feature branch
git branch -d feature

Exercise 3: Conflict Resolution
1.Create two branches from main
git checkout -b branch1


Edit the same file:

echo "Change from branch1" >> README.md
git add README.md
git commit -m "Edit README in branch1"


Create second branch:

git checkout main
git checkout -b branch2


Edit the same line/file:

echo "Change from branch2" >> README.md
git add README.md
git commit -m "Edit README in branch2"

2.Merge one branch into main
git checkout main
git merge branch1

3.Attempt to merge the second branch
git merge branch2


Merge conflict occurs

4.Resolve the conflict manually

Open README.md and fix:

#<<<<<<< HEAD
Change from branch1
=======
Change from branch2
>>>>>>> branch2


Edit to:

Change from branch1
Change from branch2


Save the file.

5.Complete the merge
git add README.md
git commit -m "Resolve merge conflict"

Exercise 4: GitHub Collaboration
1.Fork a sample repository on GitHub

Open GitHub

Click Fork

2.Clone it to your local machine
git clone https://github.com/your-username/repository-name.git
cd repository-name

3.Create a new branch
git checkout -b update-readme

4.Make changes and push to your fork
echo "Updated documentation" >> README.md
git add README.md
git commit -m "Update README"
git push origin update-readme

5.Create a Pull Request

Go to GitHub

Click Compare & Pull Request

Add title & description

Submit PR

Exercise 5: Advanced Workflow
1.Initialize a repository with multiple files
mkdir AdvancedRepo
cd AdvancedRepo
git init
touch index.html app.js style.css
git add .
git commit -m "Initial project files"

2.Create a .gitignore file
touch .gitignore


Add content:

node_modules/
.env
*.log


Commit:

git add .gitignore
git commit -m "Add gitignore file"

3.Use git stash to save work in progress
echo "Temporary change" >> app.js
git stash


Restore:

git stash pop

4.Create and tag a release
git tag -a v1.0.0 -m "First stable release"

5.Push everything to GitHub including tags
git remote add origin https://github.com/your-username/AdvancedRepo.git
git push -u origin main
git push origin --tags
